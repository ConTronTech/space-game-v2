# Dev log

Every "leap" (a chunk of verified work) gets an entry: what changed, how it was verified, the build state, known issues, what is next.
Newest first. `main` is only ever updated from a green state, and each verified state is tagged `good-YYYYMMDD-NN`, so there is always a
known-good point: `git checkout good-YYYYMMDD-NN` (or `git tag -l 'good-*'`). The binary `space_game_v2` in the repo root is rebuilt from `main`
only after the full check passes, so it should always run.

## Unattended-session rules (user asleep, 2026-09-20 onwards)
1. Never leave `main` or the root binary broken. Work happens in worktrees/branches; merge only after `package/tools/smoke.sh` passes.
2. After every merge: rebuild, run smoke + `make test-san`, run the game headless once, tag `good-*`, add a log entry here.
3. Agents never commit; every diff is reviewed before it is committed (see docs/WORKFLOW.md).
4. If quota runs out or something cannot be fixed cleanly: stop at the last green tag, write down the state in `docs/RESUME.md`, and do not start half-finished changes on `main`.
5. New ideas from the user go to `docs/ROADMAP.md` (parked ideas) / `docs/VISION.md`, not straight into code.

## Leap 31 - 2026-09-21 (DONE, tag `good-20260921-27`): fix HP drain from holding thrust against a surface (2.1c, user bug report)
- **Root cause (reproduced with a new `--hold=thrust:1` dev flag):** holding thrust into a static surface re-entered it a few steps after each push-out + bounce; physics reported a new start-touching `Collided` each time and every event applied `collisionDamage`, which is at least `ship.damage_min` (1 HP) at ANY speed: ~20 hits/s = ~20 HP/s (rock: 100 to dead in ~6 s).
- **Fix:** `ship.damage_min_speed` (3 m/s) scrape threshold (no damage, sound or bounce, push-out kept); resting contact removes only the closing velocity component so the ship slides; `ship.contact_cooldown` (0.6 s) so the same body damages at most once per cooldown; the sun is still lethal, warp and docking untouched. After (9 s held thrust): rock 13.6 + 4.7 HP from the two real impacts then nothing, planet 19.2 + 6.7 then nothing; a real 100 m/s planet impact still does 25.1 HP and bounces as before.
- **Verified:** 403 tests under ASan+UBSan (7 new incl. a 5 s held-thrust simulation: 0 damage new vs >20 hits old), smoke (37 modules), headless clean. Not verified: the feel/sound while sliding.
