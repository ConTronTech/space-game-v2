# Config (tunables)

Every tweakable number has a **base value in code** and an optional **override in `config/game.json`**.
You only ever change the JSON; the built-in default is always there as the fallback.

```json
"flight": {
  "drift": "DEFAULT",       // default 1.0 - 1.0 = pure Newtonian, nothing slows you. 0.0 = strong flight assist
  "max_speed": 120          // default 0.0 - speed cap in m/s, 0 = unlimited   <- overridden
}
```

- `"DEFAULT"` (or the key missing) = use the built-in value.
- Replace it with your own number / `true` / `false` to override. Applied on next launch.
- A value of the wrong type prints a `[config]` warning and falls back to the default.
- `config/game.json` is generated by the game: every tunable a module asks for is added as `"DEFAULT"` with a
  comment showing the real default and what it does. Your edits are kept; new tunables get appended.
  It is git-ignored (it is your personal tuning). Delete it to reset everything.

## In a module
```cpp
float thrust = eng.config.get("flight.thrust", 40.0f, "forward acceleration, m/s^2");
bool  assist = eng.config.get("flight.assist", false, "start with flight assist on");
```
Keys are `module.name` (dotted = nested object). Types: number, bool, string. Read them once in `init`.
Put every number a player might want to tune here instead of hard-coding it.

## Current tunables
- `engine.fixed_hz` - physics steps per second
- `flight.*` - `thrust`, `turn_rate`, `turn_tau`, `engine_tau`, `drift`, `assist_strength`, `brake`, `max_speed`

Related but separate files: `config/input/*.json` (bindings), `config/ui/theme.json` (glass look).
